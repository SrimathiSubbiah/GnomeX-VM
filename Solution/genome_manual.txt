1. OVERVIEW
============

The GenomeX Virtual Machine (GVM) is a programmable 8-bit processor
that executes instructions encoded as synthetic DNA sequences.

Programs are stored as strings of DNA bases (A, C, G, T) rather than
traditional binary. Each group of 3 consecutive bases forms a "codon"
which encodes 6 bits of data.


2. REGISTER ARCHITECTURE
=========================

The GVM contains four general-purpose registers:

    R0  - General purpose / accumulator
    R1  - General purpose
    R2  - General purpose
    R3  - General purpose / stack pointer

All registers are 8-bit unsigned (range: 0x00 to 0xFF).


3. PROGRAM COUNTER
===================

    PC  - 16-bit program counter

The PC holds the index of the current instruction in the program.
It increments by 1 after each instruction fetch, unless modified
by a jump instruction.


4. STATUS FLAGS
================

    Z   - Zero flag: Set when an ALU result is 0x00
    C   - Carry flag: Set when an ALU result exceeds 0xFF

Flags are only modified by arithmetic/logic instructions.


5. MEMORY MAP
==============

Total addressable memory: 256 bytes (0x00 to 0xFF)

    Address Range    Size     Purpose
    ─────────────    ────     ──────────────────────────
    0x00 - 0x3F      64B      Program code region
    0x40 - 0x7F      64B      Constants / data
    0x80 - 0xBF      64B      Encrypted key storage
    0xC0 - 0xFF      64B      Scratch / stack


6. INSTRUCTION FORMAT
======================

Each instruction is encoded as exactly 3 codons (9 DNA bases).

    Codon 1 (3 bases)  → Opcode
    Codon 2 (3 bases)  → Destination + Source fields
    Codon 3 (3 bases)  → Immediate / Address field

DNA Base Encoding:
    A = 00 (binary)
    C = 01
    G = 10
    T = 11


7. INSTRUCTION SET (PARTIAL)
==============================

The following opcodes have been confirmed through testing:

    Opcode   DNA     Mnemonic   Description
    ──────   ────    ─────────  ─────────────────────────
    0x0      AAA     NOP        No operation
    0x1      AAC     LOAD       Load byte from memory into register
    0x2      AAG     STORE      Store register byte to memory
    0x3      AAT     MOV        Copy register to register
    0x4      ACA     ADD        Add source to destination
    0x5      ACC     SUB        Subtract source from destination
    0x6      ACG     XOR        Bitwise XOR
    0x7      ACT     AND        Bitwise AND
    0x8      AGA     OR         Bitwise OR
    0x9      AGC     CMP        Compare (sets flags only)
    0xA      AGG     JMP        Unconditional jump
    0xB      AGT     JZ         Jump if zero flag set
    ???      ???     ???        [REDACTED]
    ???      ???     ???        [REDACTED]
    0xE      ATG     PRINT      Output register value
    0xF      ATT     HALT       Stop execution


8. EXAMPLE PROGRAM
===================

The following program loads a byte from address 0x40, XORs it
with a register value, and stores the result at address 0x80:

    LOAD  R2, 0x40        ; Load XOR key from memory
    LOAD  R0, 0x50        ; Load data byte
    XOR   R0, R2          ; XOR with key
    STORE R0, 0x80        ; Store result

9. NOTES
=========

- All arithmetic is modulo 256 (8-bit wraparound)
- The stack grows downward (PUSH decrements R3)
- Stack memory occupies 0xC0 - 0xFF
- The program code region (0x00 - 0x3F) is read-only at runtime
- Unknown opcodes should cause the VM to halt with an error
